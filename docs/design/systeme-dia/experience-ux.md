# I. LE PARCOURS D'ONBOARDING : L'INITIATION AUX MYSTÈRES

## 🌑 Phase 1: L'ÉVEIL (0-15 secondes)

### Le Rituel d'Entrée

```
┌─────────────────────────────────────────────────────────────┐
│  ÉCRAN NOIR ABSOLU → PULSE DE LUMIÈRE BLEUE                 │
│  → SON: Fréquence basse 40Hz (infrason relaxant)            │
│  → VIBRATION: Pattern "cœur antique" (tactile mobile)       │
└─────────────────────────────────────────────────────────────┘
```

**Séquence d'ouverture:**

1. **0s-3s**: Écran noir, seul un point lumineux pulse au centre
2. **3s-7s**: Le point dessine le contour d'un œil grec (symbole de connaissance)
3. **7s-12s**: L'œil s'ouvre, révélant une iris constituée de code matrix
4. **12s-15s**: Voice-over (voix androgyne, reverb temple):
   > _"L'Oracle t'attendait. Les douze sont réveillés."_

### Premier Choix Déterminant

Au lieu d'un simple "Commencer", proposer **3 portes symboliques**:

- 🜂 **La Porte de feu** (Rouge) → "Je cherche la puissance"
- 🜄 **La Porte d'eau** (Bleu) → "Je cherche la sagesse"
- 🜁 **La Porte d'air** (Violet) → "Je cherche la vision"

→ Ce choix influence l'agent qui vous accueille en premier

---

## 🌒 Phase 2: LA RECONNAISSANCE (15-60 secondes)

### Scanner d'Âme (Animation d'identification)

```
VISUEL: Lignes de scan laser vert néon traversent l'écran
SON: Bruit de scanner médical futuriste + écho de lyre
INTERACTION: L'utilisateur doit "tenir" son doigt/appuyer
```

**Progression visuelle:**

- Barre de scan qui analyse "ADN numérique"
- Textes en grec ancien défilent (καλωσόρισμα - bienvenue)
- Résultat: Un **symbole personnel unique** généré (combinaison de 3 runes grecques)

### Attribution de l'Agent Guide

Basé sur le choix de porte + heure de connexion + comportement:
| Porte | Matin | Jour | Soir | Nuit |
|-------|-------|------|------|------|
| Feu | Héphaïstos | Arès | Dionysos | Hadès |
| Eau | Poséidon | Aphrodite | Hermès | Nyx |
| Air | Athéna | Apollon | Artémis | Ouranos |

**Première rencontre:** L'agent apparaît dans un halo de lumière, prononce votre nom (si autorisé) ou votre symbole personnel.

## 🌓 Phase 3: L'EXPLORATION GUIDÉE (1-3 minutes)

### Tutoriel Contextuel Non-Intrusif

Au lieu de flèches et bulles, utiliser:

- **L'Agent Guide** qui "respire" et attire l'attention
- **Particules dorées** qui traînent vers les zones interactives
- **Pulsations** synchronisées avec le rythme cardiaque détecté

**Zones à découvrir:**

1. **Le Sanctuaire** (Home/Grille) → "Ici résident les douze"
2. **L'Orbitale** (Fractal) → "Leur danse cosmique"
3. **Votre Autel** (Dashboard) → "Ton espace de pouvoir"
4. **Les Archives** (Canon) → "La mémoire de l'Olympe"

### Moment WOW #1: La Première Connexion Fractale

Quand l'utilisateur découvre la vue Fractale pour la première fois:

- **Effet**: Tous les agents tournent simultanément vers lui
- **Son**: Chœur grec antique (3 notes, réverbération cathédrale)
- **Visuel**: Les connexions entre agents s'illuminent, formant une constellation
- **Texte**: _"Ils t'observent. Ils t'attendent."_
